## 💼 Чем занимаюсь

- 🔌 **Сеть роботов (C++)** — система управления подключением: автоматическое подключение к Wi-Fi, контроль состояния связи, диагностика сбоев по журналам роутера, совместимость с роутерами двух поколений
- 🖥 **Интерфейс робота (Vue.js + TypeScript)** — сценарии управления уборкой, карты и расписания, мониторинг датчиков, диагностика ошибок
- 🛠 **Автоматизация (Python)** — утилита сборки ПО робота из двух репозиториев с автоопределением совместимых версий (работает в CI), сервисы на Flask, обмен данными между процессами через общую память
